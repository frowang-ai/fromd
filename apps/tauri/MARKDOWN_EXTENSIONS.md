# Markdown 渲染扩展

现用 Milkdown/ProseMirror 正文与共享 PDF 文档支持 YAML front matter、Mermaid、脚注和 GitHub 提示块。
仍通过「视图 → 源码」编辑完整 Markdown，不增加编辑模式或常驻工具栏。

## YAML front matter

文件最前面的 `---` 围栏块显示为浅灰色原文元数据块，深色主题使用对应深色背景。
等宽文字按正文正常字号显示，保留换行、缩进、注释、引号和 `>-` 等字面写法。
直接点击灰块中的文字即可定位光标、输入、选择、复制或粘贴；Enter 保留上一行缩进，Tab / Shift+Tab
调整缩进，长行自动换行。没有额外编辑按钮；`Ctrl+/`（macOS `⌘/`）仍切换完整 Markdown 源码。
块内撤销/重做与正文共用单页历史，切页保留光标选区，输入沿用自动保存、组合输入等待和保存冻结。
只编辑正文时，YAML 前缀（包括 BOM、CRLF、围栏尾部空格及其后空行）原样保留；
打开或选择 YAML 不改变原文，实际编辑该块时换行统一为 LF，其余围栏写法与分隔空行保留。

上下围栏固定显示，内部作为纯文本编辑。点击围栏可选中整块复制/剪切；在内部选择仅复制所选文字。
粘贴完整的单个元数据块时取其内部文字，保留当前围栏；内部不能新建无缩进的独立 `---` 或 `...` 行，
这类输入会提示并取消，避免元数据在重读时提前闭合。需要改变围栏时使用完整源码入口；
移除整个块可点击围栏选中后删除。清空内部文字保留空元数据块。
光标在最后一行按 ↓ / 文末按 → 可返回正文，正文首行按 ↑ 可进入 YAML。

识别只依赖围栏，不解析或执行 YAML：第一行可带 BOM，必须为无缩进的 `---`（可跟空格或 Tab）；
第一个无缩进的 `---` 或 `...` 行结束该块。支持 LF、CRLF 和 CR，结束行可以直接到文件末尾。
空块、语法暂时无效的 YAML 都按原文展示，不生成属性表、加载资源或请求网络。
未闭合前缀、开头空行/缩进、正文后面的分隔线、Setext 标题及代码围栏里的 `---` 按普通 Markdown 处理。
在文首以完整围栏包围的文字，即使不像键值表，也视作元数据；这是语法边界，不做内容猜测。
大纲与字数统计排除同一完整块；未闭合前缀中的正文继续参与大纲和统计。

共享 PDF 使用同一边界，以转义后的原文块打印 YAML，不套标题、不执行其中的 HTML 或公式。
纯文本粘贴到文首可形成元数据，粘贴或移动到其他位置后按普通 Markdown 处理。
粘贴到正文或表格时，其中的 Markdown 图片/附件按普通资源规则检查：已登记资源绑定到目标页，
未知引用使整次粘贴取消；文首 YAML 中的引用仍是字面文本，不登记、不加载。
正文模式下，若拖放或在 YAML 前新增块会激活其中的受管资源引用，本次操作会被阻止，
并提示改用复制或剪切后粘贴，让资源检查先完成。
回归入口为根 `tests/frontmatter.test.mjs`、共享 `tests/editor.browser.spec.mjs` 的 YAML 用例，
以及 Tauri `tests/frontmatter.browser.spec.mjs`、`tests/frontmatter-resources.browser.spec.mjs`；
真实安装和原生 PDF 物理分页需另行验收。

## Mermaid、脚注与提示块

````markdown
```mermaid
flowchart LR
  A[开始] --> B[完成]
```

正文引用[^named]，可以重复引用[^named]。

[^named]: 第一段脚注，支持 **格式** 和 [链接](https://example.com)。

    缩进四个空格可继续第二段。

> [!NOTE]
> 这里写提示内容。
````

Mermaid 在正文显示图表，点击「编辑图表源码」使用原有代码块编辑器修改；
完成后可收起源码。编辑、撤销、切页与保存保留代码块本身，图表只是派生预览。
语法未完成或不支持时显示局部反馈，源码不丢失。支持常用 flowchart/graph、sequenceDiagram、
classDiagram、stateDiagram、erDiagram、gantt、pie、journey、gitGraph、mindmap、timeline 等离线图表。
每图最多 50,000 字符、500 条边。允许无属性的 `<br>`、`<br/>`、`<br />` 及其大小写变体作为换行；其余 HTML 标签和带属性的 br、配置/frontmatter 指令、点击动作、
图片和图标资源语法暂不支持；中文 flowchart 等图表标签已覆盖。当前锁定 Mermaid 12.3 的 Sankey CSV 节点名需使用 ASCII，中文说明可写在图表外。依赖随应用打包，不使用 CDN 或在线字体。

脚注引用显示命名标签，定义在其原有位置可直接编辑，未引用定义也保留。
需要修改引用名或新增定义时可使用源码模式。脚注里的链接沿用普通点击编辑、Ctrl 点击打开。
保存时保留标准 `[^id]` 定义；正文编辑后可能沿用现有序列化器统一缩进与空行。

提示块支持 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]`，
标记单独占引用块第一行，且标记本身必须是无格式的纯文本；`[!*NOTE*]` 等带 marks 的写法在正文和 PDF 中均视为普通引用。正文保留可编辑标记，并以颜色和边线区分。编辑后保存会将合法首段标记恢复为标准 `[!NOTE]` 拼写；旧文件中的 `\[!NOTE]` 也按相同纯文本规则识别，代码和普通正文不受影响。

空行内公式在屏幕保留 `〈空公式〉`，可再次点击编辑。保存使用 `$ $`（单空格）表示空值，纯空白公式也归一为这一表示；项目锁定的 remark-math 可以解析此语法，重读恢复空节点，PDF 安静忽略空公式且保持同一段落。不会写成含混的 `$$`，也不会用人为 LaTeX 命令代替用户源码。组合回归见 `semantic-roundtrip.browser.spec.mjs`。

共享 `buildPdfDocument({markdown,title,resolveImage})` 保持原签名，兼容同步图片 resolver，
也接受 Promise。它从完整 Markdown 构造文档，等待所有 Mermaid 图表完成，
输出经过专用清洗、带 viewBox 和尺寸的内联 SVG；不依赖编辑器是否滚动到图表。
脚注和提示块同样进入打印文档，未引用脚注定义也包含在内。
图表有错误时整个导出失败并说明原因，不将空白或占位图当作成功。
此能力不改变 Tauri 原生 PDF 菜单/打印接线，也不放宽原始 HTML/SVG 的清洗规则。

浏览器回归入口：`apps/tauri/tests/markdown-extensions.browser.spec.mjs`，
包含实际图表可见性、编辑/源码往返、跨页 undo/redo、保存读回、局部错误、
脚注链接交互、完整打印文档及无外部资源请求检查。
