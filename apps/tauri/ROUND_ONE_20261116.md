# Tauri 第一轮整合（2026-11-16）

本轮以 `feat/tauri-blackboard-v1` 的 `f648c93` 为基线，对照 Electron 0.5 的功能补齐差异。
运行主体是已有的 Tauri/Rust 客户端和 Windows WebView2；原 Electron 工程保留，
其代码、安装包与验收记录不能作为 Tauri 已完成相同原生验证的证据。

## 保留的 frowd 交互

页面可以先写再命名，SQLite 保存本地文档及页面状态。左侧页面/大纲工作栏、
标签与侧栏减号、全部展开、页面排序、浮动名称/保存状态、收起后恢复均继续使用。
收起保留450ms动效，恢复直接显示正文。页面只有一套活跃 Milkdown/ProseMirror 编辑器，
各篇保存会话历史与阅读位置；源码模式使用既有 EditorPort，不增加编辑内核切换入口。

## 本轮补齐

- **阅读与统计**：原大纲位置支持 ATX、Setext 和引用标题，排除文首 YAML 元数据、
  代码伪标题；重复标题保留独立定位。浮动栏显示字词和非空字符统计，包含代码与公式源码。
  字号14/16/18/20、宽度720/860/900/1080、浅色/深色/跟随系统按需设置；默认保留16px、
  860px和浅色。偏好仅写应用 localStorage，失败有反馈。见 [READING_V1](READING_V1.md)。
- **已有搜索补强**：复用 Tauri 的 SQLite 全文搜索及正文/源码查找替换，新增“区分大小写”
  选项；开关随查找目标身份核对，全文搜索语义不变。修复源码命中滚动与焦点、CRLF到
  textarea的坐标转换，保留原 Markdown 与文档归属。见 [FIND_REPLACE_V1](FIND_REPLACE_V1.md)。
- **已有资源服务补强**：复用按 docId 登记的持久图片/附件、粘贴、拖入与另存链。
  另存现在也识别原始 HTML `<img src>` 的文档相对图片，保留相对引用并按既有目录边界和
  冲突规则复制。HTML注释、代码及脚本/样式等原始文本中的伪标签不产生资源授权；
  远程或绝对图片、普通文件链接仍不作为另存附件复制。见 [RESOURCES_V1](RESOURCES_V1.md)。
- **稳定性**：继续使用协调器串行操作、IME等待、真实 readonly/inert 冻结、保存确认和退出
  握手。阅读 CSS 不重建编辑器；普通代码和公式深色高亮保留浅色回退，打印样式独立。

本轮没有迁入 SoloMD 的云同步、AI、recipes、MCP sidecar 或更新服务。PDF/Office导出、
真实数据迁移、安装器与移动端仍不在这一轮验收范围。

## 入口和隔离运行

以下命令从仓库根目录执行。`npm run dev/build` 仍是旧 Electron；
Tauri 子工程自己的 Vite 命令由 `tauri:*` 脚本调用。

| 命令 | 用途 |
| --- | --- |
| `npm run tauri:web` | Tauri 前端类型检查和构建 |
| `npm run tauri:dev` | 开发模式原生 Tauri 窗口 |
| `npm run tauri:check` | Rust 宿主检查 |
| `npm run tauri:build` | release no-bundle 构建，仅生成可执行文件 |
| `npm run test:tauri` | Tauri Node 测试 |
| `npm run test:tauri:browser` | 浏览器与模拟 IPC 回归 |
| `npm run test:tauri:native` | debug exe + 真实 WebView2 / SQLite 回归 |

本机工具链为 Rust1.93.1、MSVC14.44、Windows SDK10.0.26100、WebView2 157。
在 VS Developer PowerShell 中准备独立临时目录，然后构建原生测试所需 debug exe：

```powershell
$nativeTemp = Join-Path (Get-Location).Path 'output/native-temp'
New-Item -ItemType Directory -Force -Path $nativeTemp | Out-Null
$env:TEMP = $nativeTemp
$env:TMP = $nativeTemp
$env:CARGO_BUILD_JOBS = '4'
cargo test --manifest-path apps/tauri/crates/document-store/Cargo.toml --locked
npm --prefix apps/tauri run tauri -- build --debug --no-bundle
npm run test:tauri:native
```

原生测试会创建合成 profile。手动检查时同样要隔离文档库和 WebView2 存储：

```powershell
$taskProfile = Join-Path (Get-Location).Path 'output/native-review-profile'
$taskWebView = Join-Path $taskProfile 'webview2'
New-Item -ItemType Directory -Force -Path $taskProfile,$taskWebView | Out-Null
$env:FROWANG_USER_DATA = $taskProfile
$env:WEBVIEW2_USER_DATA_FOLDER = $taskWebView
npm run tauri:dev
# 正常关闭后，可使用同一组路径再次启动检查恢复。
Remove-Item Env:FROWANG_USER_DATA
Remove-Item Env:WEBVIEW2_USER_DATA_FOLDER
```

`FROWANG_USER_DATA` 仅在 debug 构建有效。不要启动 release exe 来验证隔离 profile。
release no-bundle只构建，不安装、不公开发布、不启用更新；应用身份为
`com.frowang.frowd.tauri.v1`，不接管已有 Electron 安装或自动导入其用户数据。
