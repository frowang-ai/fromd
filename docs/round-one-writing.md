# 第一轮写作功能（0.5.0）

本轮围绕新建、写作、收起、找回和保存页面扩展。未命名页面可以直接写作、粘贴图片和自动恢复。大纲、搜索和阅读设置按需展开。

## 查找与页面搜索

- `Ctrl+F` 打开页内查找，`Ctrl+H` 打开替换。支持字面量、区分大小写、前后匹配、替换当前和全部替换。富文本替换经过 ProseMirror 事务，源码替换保留 Chromium 原生撤销。
- 页内查找包含跨格式文字、代码块和行内公式。查找栏打开时，继续输入正文会更新匹配数并保留光标。匹配超过 10,000 处时显示上限，全部替换需缩小查询范围。
- `Ctrl+Shift+F` 打开页面列表，搜索标题和正文，包括收起、重启后未访问的页面。每篇返回第一个命中片段，点击打开页面并定位。隐藏链接地址等 Markdown 语法命中会切换到源码选中。
- 全文搜索在 SQLite worker 中逐篇进行，向界面返回命中元数据。已修改但备份失败的正文仍参与搜索。输入变化、移除页面和异步回执使用请求身份检查。
- 搜索使用应用中的草稿内容。关联文件的外部变化继续在打开该页或保存时核对。

## 图片

- 正文与源码支持截图粘贴、图片拖入。正文拖放按落点定位，源码使用当前选区。HTML 表格粘贴继续走既有表格恢复流程。
- PNG、JPEG、GIF、WebP 每张最多 10 MiB，每批最多 20 张、总计 50 MiB。renderer 先检查文件数量和大小，main 再校验字节、签名与 MIME。
- 图片先写入用户数据目录的 `_frowd-assets/<sha256>.<ext>`，写入确认后插入相对链接。草稿退出重启、页面收起恢复及本会话删除撤销均可继续读取图片。
- 保存或另存 Markdown 时，先复制所引用的附件，再原子写入正文。另存已有文件时也复制文档目录内的相对图片，包含引用式与 HTML 图片。目标已有同名异内容图片会提示冲突。
- 正文保存失败保留原草稿身份和内容。失败、撤销插图或删除页面后留下的未引用附件暂时保留，支持撤销及恢复。本轮没有附件自动清理。
- 异步导入过程中页面身份变化会取消插入并提示，已落盘的附件可在重新插入时复用。

## 大纲、统计与阅读设置

- `Ctrl+Shift+O` 或顶栏“大纲”显示标题列表。支持 ATX、Setext 标题，排除代码中的伪标题。点击前重新核对当前正文，再定位富文本或源码。
- 右下角显示字词与非空字符数。汉字、假名和韩文逐字，英文和数字按词，代码及公式源码参与统计。Markdown 标记和图片路径不计入正文统计。
- 顶栏“阅读”或 `Ctrl+,` 设置字号 14／16／18／20 px、正文宽度 720／900／1080 px，以及浅色、深色、跟随系统主题。设置单独保存在本机应用 localStorage，保存失败有反馈。
- 主题覆盖应用内容、页面卡片、搜索和代码／公式编辑区域，收起动效取当前主题颜色。Windows 原生标题栏和菜单沿用系统外观。
- 新功能沿用既有按需编辑会话、IME 等待、保存与退出握手。编辑包保持独立于 Electron。

## 验证入口

`npm test`、`npm run build`、`npm run test:desktop`、`npm run test:editor`。新增真实桌面用例分别位于 `tests/search.desktop.spec.mjs`、`tests/images.desktop.spec.mjs` 和 `tests/reading.desktop.spec.mjs`。所有笔记、图片及 profile 为隔离合成样本，实际结果见 `VALIDATION.md`。
