# 标签与收起动效预览

独立交互预览，用于确认标签形态和更明确的收起去向。与桌面接入共用任务分支 / PR #8。此HTML保留最初450ms收起、400ms展开的双向示例。用户后续选择仅保留收起动效，桌面0.4.2恢复页面直接显示；示例中的展开动画不再代表当前产品行为。桌面收起使用Electron真实画面捕获而非此HTML的SVG快照。行为与入口见 [page-shelf.md](page-shelf.md)。

## 打开

用 Chrome / Edge 直接打开 [page-shelf.html](../output/visualizations/page-shelf.html)，不需要联网、依赖或构建。

也可在已安装依赖的 checkout 中运行：

```powershell
node node_modules/vite/bin/vite.js output/visualizations --host 127.0.0.1 --port 5198 --strictPort
```

访问 `http://127.0.0.1:5198/page-shelf.html`。当前 worktree 的本机服务复用来源仓库的 Vite 路径；直接打开文件则不需要 Vite。

HTML 是明确跟踪的原型源码，所在 `output/` 默认忽略。后续用 `git add -f output/visualizations/page-shelf.html` 只暂存这个文件，截图和检查结果不提交。

## 体验

- 名称和减号共享整个标签的底色/悬停范围。右上角预览设置可切换“一体 / 细线”，以及慢放、重置。
- 点击当前标签的减号：整页上沿先向左上角入口弯曲并收尖，余下页面随之吸入；入口给出一次短暂的落点反馈。
- 点击左上角页面入口，再点卡片：以反向动效展开。收起非当前标签时只收走该标签，不动正在阅读的正文。
- 卡片右上角 × 删除，底部只保留“已删除 / 撤销”。列表不再放说明性小字。
- 示例标题和正文可编辑。收起/展开保留本次编辑和滚动；全部收起、删除撤销、新建、搜索以及 Escape 关闭列表可体验。

## 实现边界

当前为单文件 HTML 示例，状态只在页面内存里；刷新或关闭页面会重置。它不读取真实笔记、SQLite、Electron 或 localStorage，不是正式编辑内核。

动效将可见正文放进自包含 SVG / foreignObject，先光栅化为一次性的 Canvas 纹理，再按薄行变换成曲面；内容随页面弯曲，不只是裁切轮廓。正常收起450ms、展开400ms，慢放2400ms。结束或窗口尺寸变化时清理画布，系统减少动态效果时直接完成动作。捕获/绘制异常也会释放交互锁并完成收起或恢复，通过屏幕阅读器状态和控制台记录失败。

没有网络字体、图片依赖、运行时请求或额外渲染库；当前只验证 Chromium，不能据此承诺所有浏览器、任意复杂页面或大文档下的动效性能。真实编辑器接入与对应验证归桌面运行路径，实际结果见 `../VALIDATION.md`。

## 本轮核查

真实 Chrome（`agent_browser`）操作并查看截图：

- 正常吸入与反向展开确实生成曲面画布，完成后画布及交互锁均清理。
- 编辑40段内容并滚动180px后，收起/恢复保留名称、末段正文和滚动位置；空标题第一次点击也能收起。
- 删除/撤销、全部收起空状态、非当前标签收起、两种标签样式、慢放。
- 动画中调整窗口尺寸可完成动作并清理画布；390×844窄窗无整页横向溢出，过长标签在标签栏内滚动。
- 系统减少动态效果下不创建飞动画布；直接 `file://` 打开可用，观察流程无未预期的控制台错误。
- 独立审核 PASS；唯一 low（收起失败播报被成功消息覆盖）已合并成一次播报。注入绘制异常后确认提示保留、画布清理、交互解锁；加速后的正常收起/展开也已实测。
