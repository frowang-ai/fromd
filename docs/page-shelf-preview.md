# 页面收起交互预览

这是最初的独立前端交互原型，用于体验“收起页面”和“删除页面”的区别。后续已在同一任务分支按现有编辑器风格接入桌面运行路径，见 [页面收起说明](page-shelf.md)；本HTML仍是刷新重置的独立示例，已交付的0.3.0安装器未被替换。

## 打开

直接用 Chrome / Edge 打开仓库内的 [page-shelf.html](../output/visualizations/page-shelf.html)，无需安装依赖、构建或联网。HTML、样式、脚本和示例均在一个文件里。

也可以在已安装依赖的 checkout 中运行：

```powershell
node node_modules/vite/bin/vite.js output/visualizations --host 127.0.0.1 --port 5198 --strictPort
```

然后打开 `http://127.0.0.1:5198/page-shelf.html`。独立 worktree 没有依赖时，可以把命令中的 Vite 路径指向来源仓库已安装的版本；直接打开 HTML 不需要 Vite。

此文件是明确提交的原型源码，尽管所在的 `output/` 默认被忽略，Git 仍会跟踪该 HTML；截图和检查输出继续忽略。后续修改用 `git add -f output/visualizations/page-shelf.html` 明确暂存这个文件，避免忽略目录的提示；不要把整个输出目录加入提交。

## 体验顺序

1. 初始打开三篇页面，另有两篇已收起。可以直接编辑标题和正文。
2. 点击标签旁的 **−**：当前页面缩入左侧“页面”入口，顶部标签消失，内容保留。收起非当前标签时保留眼前正在读的页面。
3. 点击左侧“页面”：浮出正文缩略卡片；支持按标题搜索、“全部 / 已收起”筛选。
4. 点击卡片：展开到正文区域，恢复本次编辑和滚动位置。
5. 卡片右上角 **×**：直接删除页面，底部出现“撤销删除”。撤销保留到关闭该提示或下一次删除；仅支持最近一次删除。
6. 把所有标签收起：显示“桌面清空了，页面还在”，不会自动生成一个空白标签。所有页面删除后可以新建或撤销最后一次删除。
7. 勾选底部“慢动作”，放慢收起与展开的动画；“重置示例”恢复初始内容。

面板可用 Escape 或点击面板外收起。标题标签可用方向键及 Home / End 切换；关闭面板时焦点回到左侧入口。系统设置减少动态效果时跳过页面飞行动画与过渡。

## 范围

- 示例内容仅存在当前浏览器页面内存，**刷新、关掉浏览器页面或重置示例会清除本次编辑**。界面始终显示“示例内容 · 刷新重置”。不用于真实笔记。
- 不读取实际用户笔记、SQLite、文件系统或应用设置，不使用 localStorage，不修改已安装的编辑器。
- 预览正文是浏览器 `contenteditable="plaintext-only"`，示例带预排版；不是正式 Milkdown/ProseMirror 编辑器，不承诺 Markdown 格式解析、公式编辑、IME 或 undo/redo 等正式编辑契约。
- 缩略图取示例正文 DOM；飞行动画用短暂 DOM 副本。它验证展示方式，不代表大量笔记下的性能结论。
- 此HTML只演示视觉和交互。桌面接入的持久化、重启恢复和删除契约见 [页面收起说明](page-shelf.md)，不由此HTML承担。

## 本轮验证

使用原生 `agent_browser` 的 Chrome / Playwright 浏览器操作核查，并实际查看桌面、窄屏截图：

- 标题和36段正文编辑 → 滚动180px → 收起 → 从卡片展开：标题、末段正文与180px阅读位置均保留。
- 删除当前页面：卡片和标签一起消失、总数减一；撤销后内容、标签和位置恢复。
- 按标题搜索、只看已收起页面、收起全部标签、删除全部页面、最后一次删除撤销、新建和重置。
- 标题中的 `<script>` 按字面文本显示，不作为 HTML 插入。
- 独立审核发现清空标题后第一次点击减号被失焦重绘打断；先复现，再移除失焦时多余的标签重建。空标题首次收起、纯空格标题首次切换均复验通过。
- 1320×900桌面与390×844窄屏，页面面板处于窗口内，无页面级横向溢出；减少动态效果设置下无残留动画。
- 直接打开 `file://` HTML 可以使用；已观察流程无浏览器运行错误。
