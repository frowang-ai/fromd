# 页面收起与移除

本任务分支在现有桌面编辑器中接入页面列表。界面沿用原有背景、字号和紧凑布局，名称与减号共享一体标签的底色和悬停范围；顶部标签的减号表示收起，左上角“页面列表”可查看全部页面，卡片右上角 × 表示删除草稿或从列表移除文件页面。列表不放说明性小字。

## 行为

- **收起**：先完成编辑、名称和阅读位置保存，再持久化收起状态。只隐藏顶部标签，正文仍留在本地 SQLite。收起全部页面后显示空桌面，新建和打开菜单仍可用。
- **恢复**：点卡片重新打开，同一会话保留原编辑会话；重启后恢复已保存的正文、名称、源码模式和阅读位置。撤销/重做历史仍不承诺跨重启保留。
- **删除草稿**：移除 SQLite 中的当前记录；本次应用会话保留最近一次移除的内容供撤销，不是长期回收站。
- **移除文件页面**：不删除磁盘 `.md` 原文件；存在未写回修改时保留“保存 / 不保存 / 取消”对话框。仅收起不会要求另存或写回文件。
- **撤销移除**：恢复正文、名称、顺序与收起状态，使用新的内部 ID，避免删除前的迟到请求覆盖恢复后的页面。如果同一磁盘文件已经重新打开，旧内容恢复成独立草稿并明确提示，不覆盖重新打开的页面。下一次移除或退出应用后不再保留上一次撤销记录。
- 持久化失败时不完成收起、移除或撤销，页面与待保存内容继续保留，恢复存储后可以重试。
- 搜索只按标题匹配。卡片正文是最多1200字符的开头预览，不为打开列表而读取完整正文；进入视野后才渲染 Markdown，预览不加载图片和媒体。
- 收起当前页时，整页向左上角页面入口弯曲收尖后吸入，持续450ms；从卡片展开时反向播放400ms。入口有一次轻微落点回应。系统开启减少动态效果时连画面捕获一起跳过。
- 动画使用 Electron 当前窗口的实际可见画面，因此公式、图片、源码框文字及滚动位置随页面一起变化。捕获不写文件、不上传，像素和PNG大小有界；帧结束、窗口尺寸/滚动/可见性变化、文档失效或异常都会释放画布。动画失败只跳过动效，不撤销已完成的保存/收起，也不阻断恢复。

## 存储和接口

SQLite schema 3 为文档增加 `shelved` 字段，旧页面默认保持打开；不重新导入已迁移的 `session.json`。元数据增加有界 `preview`，`activeId` 可以为 `null`（全部收起或列表为空）。原始全文仍由固定 `read(id)` 按需读取。

新增固定 preload API：`shelve(id)`、`undoRemove()`；原 `close(id)` 作为卡片移除入口，保留绑定文件的保存确认。`capturePage()`只捕获应用自己窗口的渲染内容，复用主frame来源检查；不接受窗口ID、文件路径、区域或桌面捕获参数。捕获不占文档队列，每次最多一个在途操作；返回PNG最长2048×1536且最多8MiB。没有新增任意文件或 IPC 访问。

页面文件关联是唯一的，重新打开已收起的文件复用原页面。文件写回、外部变更检测、UTF-8/BOM/换行、PDF、更新退出握手继续沿用既有模块。

## 验证入口

- `npm test` → `tests/shelf-storage.test.mjs`：收起重启恢复、文件复用/原件保护、删除与撤销、迟到旧 ID、事务失败回滚、schema 2 迁移。
- `npm run test:desktop` → `tests/motion.desktop.spec.mjs`：实际画面捕获/曲面Canvas、450/400ms时长、文字/公式/图片、编辑/阅读状态、减少动态效果、resize/迟到事件、捕获拒绝/挂起与绘制异常清理。
- `npm run test:desktop` → `tests/shelf.desktop.spec.mjs`：真实 Electron/IPC/SQLite 的编辑与阅读状态恢复、空桌面菜单、缩略图按需渲染、卡片右上角删除/撤销、文件确认与失败重试。
- 原桌面套件的删除操作转到真实卡片按钮；名称回执、外部文件、迟到读取和第二实例回归仍保留。等待未完成正文写入的场景用受控 IPC 回执建立确定性的竞态，不依赖“人工操作恰好不足200ms”。

所有回归使用隔离 `FROWANG_USER_DATA` 和合成样本。实际结果及本轮限制记录在 `VALIDATION.md`，不把新增测试入口视为已经通过。

最初的独立 HTML 原型仍见 [page-shelf-preview.md](page-shelf-preview.md)，它是视觉探索材料，刷新重置，不是桌面数据恢复入口。
